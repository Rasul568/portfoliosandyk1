C++ тілі

C++ — жылдамдығы жоғары, жүйелік бағдарламалауда, ойындарда және ендірілген жүйелерде кеңінен қолданылатын тіл. Ол C тілінің негізінде жасалған және объектілі-бағытталған бағдарламалауды қолдайды.

Негізгі ұғымдар

  • Айнымалылар: int, double, char, bool, string
  • Шарттар: if, else, switch
  • Циклдар: for, while, do-while
  • Функциялар, массивтер, көрсеткіштер, кластар

Мысал: екі санның қосындысы

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Екі сан енгізіңіз: ";
    cin >> a >> b;
    cout << "Қосындысы: " << a + b << endl;
    return 0;
}

Мысал: 1-ден 10-ға дейінгі сандар

for (int i = 1; i <= 10; i++) {
    cout << i << " ";
}

Pascal тілі

Pascal — Никлаус Вирт жасаған, оқуға арналған тіл. Синтаксисі айқын әрі түсінікті, сондықтан бағдарламалауды алғаш үйренгенде өте ыңғайлы.

Негізгі ұғымдар

  • Айнымалылар: var бөлімінде жарияланады (integer, real, char, string)
  • Шарттар: if ... then ... else, case
  • Циклдар: for, while, repeat ... until
  • Процедуралар мен функциялар, массивтер, жазбалар

Мысал: екі санның қосындысы

program Qosyndy;
var
  a, b: integer;
begin
  write('Екі сан енгізіңіз: ');
  readln(a, b);
  writeln('Қосындысы: ', a + b);
end.

Мысал: 1-ден 10-ға дейінгі сандар

var i: integer;
begin
  for i := 1 to 10 do
    write(i, ' ');
end.
